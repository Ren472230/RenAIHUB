**Снимок:** 11.11.2026 · **Редакция документов:** v1.1 (по независимому аудиту)  
**Основной репозиторий:** https://github.com/Ren472230/RenAIHUB  
**Текущая фаза:** P0 – основание проекта  
**Реализация:** документационная основа создана; исходный ZIP проверен статически; [AnythingLLM динамически запущен на WIN01 в отдельном QA-контейнере](P04_RUNTIME_WIN01_2026-11-11.md). **Собственный Ren AI HUB и LibreChat не запускались; готовый продукт отсутствует.**

## Что подтверждено

1. Согласован принцип развития: локальный инструмент для себя → измерение реальной пользы → многопользовательский пилот → подписочная версия.
2. Публичный репозиторий на начало работы был пуст, основной веткой была main.
3. Переданный ZIP содержит **211 записей** (проверено локальным просмотром оглавления), включая код API (Fastify), admin (Next.js), desktop (Tauri), db (Prisma/PostgreSQL), Docker-конфигурацию и исторические EXE. **SHA-256 архива:** `6e8fd091dd13f204c8ceafa16d489e35ea7dd1efdbae0a8dfd4523a487dc820d`. Сам архив в репозиторий не загружен.
4. В архиве не обнаружен отдельный файл лицензии. Коммерческие права на использование и распространение кода/графики требуют проверки.
5. Документация обновлена с v1.0 до v1.1: личный HUB – первый результат, сценарий коммерческого предложения – гипотеза, защита предшествует реальным файлам, архитектура предварительна, предусмотрен независимый прототип при отсутствии прав. Сторонний исходный код, изображения, установщики, реальные секреты и базы данных не переносились.
6. [Статический аудит P0 от 11.11.2026](P0_SOURCE_AUDIT_2026-11-11.md): права не подтверждены; инвентаризация и поиск секретов проведены предварительно; обнаружены блокирующие для использования агентских файлов/обновлений риски и риск отключённой проверки TLS. Выбран условный минимальный путь – один существующий desktop-клиент с локальным API/БД после устранения блокеров; резерв – независимый собственный прототип.

7. Проведено [исследование GitHub-компонентов от 11.11.2026](GITHUB_REUSE_RESEARCH_2026-11-11.md): сопоставлены готовые платформы и модульные библиотеки, проверены опубликованные лицензии и ограничения коммерческой перепродажи. **Код сторонних проектов не копировался, библиотеки не устанавливались, сервисы не запускались.**
8. Проведён [сравнительный статический эксперимент P0](P0_COMPARATIVE_EXPERIMENT_2026-11-11.md): локальный архив прошёл проверку целостности, 74 TS/JS (0 ошибок синтаксиса) и 18 JSON (0 ошибок разбора); подтверждены ранее выявленные блокирующие риски безопасности. Для LibreChat и AnythingLLM изучены официальные манифесты, Docker-конфигурации и MIT-лицензии на зафиксированных коммитах. **После этой статической редакции выполнен частичный динамический тест варианта C на WIN01; подробности в [P0.4-отчёте](P04_RUNTIME_WIN01_2026-11-11.md). Варианты A/B остаются без динамического запуска.**

9. [Динамический отчёт P0.4 на WIN01](P04_RUNTIME_WIN01_2026-11-11.md): AnythingLLM (образ 1.19.0) запущен с внутренней Docker-сетью и лимитом ресурсов, пройдены HTTP, создание и повторное чтение проекта, диалог с моделью-заглушкой, сохранение чата после перезапуска; QA-контейнеры остановлены. **Реальный браузерный UI и A/B не проверены.**

## Как обновлять паспорт

После каждого модуля фиксировать: **изменения → ссылки на артефакты → команды/результаты проверки → блокеры → следующая задача**. Записи должны различать факт, предположение и план.
